online: https://dustinchen26.github.io/piano

## ✨ 核心功能亮點

### 1. 🎼 互動琴譜教學與自動示範 (Follow-Me Tutor)
* **亮燈跟彈指引**：選擇曲目後，下一個該按的琴鍵會亮起**琥珀金色呼吸燈與跳動紅點**，彈對自動前進，零基礎也能輕鬆彈完整首曲子。
* **示範自動演奏**：一鍵點擊「▶ 示範自動演奏」，系統會依節拍自動演奏示範，並同步點亮琴鍵與樂譜進度條。
* **內建經典曲目**：內建《給愛麗絲 (Für Elise)》、《小星星》、《卡農經典旋律 (Canon)》，並可點擊樂譜卡片任意跳轉段落練習。

### 2. 🔊 Web Audio API 即時合成音色引擎
無需載入外部 MP3 音檔，透過瀏覽器原生 Web Audio API 零延遲即時合成，並內建動態壓縮器防止多音和弦破音：
* **🎹 演奏級鋼琴**：三角波基頻搭配泛音列與動態低通濾波，模擬琴槌擊弦的溫暖共鳴。
* **✨ 夢幻電鋼琴**：雙重微失諧合唱感（Chorus）搭配清脆鐘琴泛音。
* **⛪ 教堂管風琴**：多組拉桿音栓（16' + 8' + 4' + 2-2/3'）飽滿持續共鳴。
* **👾 8-Bit 合成器**：經典方波與低八度鋸齒波，重現復古電玩音效。

### 3. 📱 跨裝置支援與寬大琴鍵設計
* **電腦鍵盤雙排映射**：支援雙手多鍵同時彈奏和弦。
* **手機 / 平板多點觸控**：支援多指和弦與手指滑奏（Glissando），建議將手機轉為**橫向（橫屏）**以獲得最寬大舒適的按鍵體驗。
* **OLED 即時頻譜視覺化**：即時顯示音頻頻譜柱、示波器聲波線，並在彈奏時從對應琴鍵向上飄散發光音符粒子。

## 🚀 快速開始

### 方式一：本機直接開啟
1. 下載或儲存 `index.html` 檔案。
2. 使用任意現代瀏覽器（Chrome、Safari、Edge、Firefox）雙擊開啟即可開始彈奏。

### 方式二：部署至 GitHub Pages（推薦手機使用）
1. 將 `index.html` 與 `README.md` 上傳至 GitHub 儲存庫（Repository）。
2. 前往儲存庫的 **Settings > Pages**，選擇 `main` 分支並儲存。
3. 取得專屬網址後，即可在手機瀏覽器打開並「加入主畫面」，像原生 App 一樣隨時練習！

## 🎮 操作指南

| 操作方式 | 對應按鍵 / 手勢 | 功能說明 |
| :--- | :--- | :--- |
| **彈奏白鍵** | `A` `S` `D` `F` `G` `H` `J` `K` `L` `;` `'` `Enter` `1` `3` `4` | 對應 `C4` 至 `C6` 共 15 個白鍵 |
| **彈奏黑鍵** | `W` `E` `T` `Y` `U` `O` `P` `]` `Backspace` `2` | 對應各組升降半音黑鍵 |
| **延音踏板** | `Space`（空白鍵）或點擊面板按鈕 | 按住可延長音符餘韻，放開後自然衰減 |
| **八度移調** | `Z`（降八度）/ `X`（升八度） | 支援 `-2` 至 `+2` 個八度音域調整 |
| **滑音演奏** | 滑鼠按住拖曳 / 手指在琴鍵上滑動 | 流暢觸發滑奏（Glissando）效果 |

> **💡 iPhone 使用小提醒**：若點擊琴鍵沒有聲音，請確認手機左側的**實體靜音開關**已關閉（設為響鈴模式），並點擊任一琴鍵以解鎖瀏覽器音訊引擎。

## ➕ 如何自訂新增歌曲？

您可以隨時在 `index.html` 的 `<script>` 區塊最上方找到 `SONG_LIBRARY` 陣列，依照以下格式貼上新曲目即可擴充歌單（支援音域為 `C4` ~ `C6`，含升記號如 `C#4`、`D#5`、`F#5`、`G#4`、`A#4`）：

```javascript
const SONG_LIBRARY = [
    // ...原有曲目...
    {
        id: 'my-custom-song',
        title: '🎶 我的自訂新曲目',
        tempo: 120, // 自動示範演奏速度 (BPM)
        notes: [
            { n: 'C5', s: '1', d: 1 },   // n: 音名, s: 簡譜/唱名顯示, d: 拍數 (1=一拍, 0.5=半拍)
            { n: 'D5', s: '2', d: 1 },
            { n: 'E5', s: '3', d: 2 }
        ]
    }
];
```

## 🛠️ 技術架構
* **HTML5 / CSS3**：客製化 3D 琴鍵立體陰影、按壓傾角動畫與琥珀金教學呼吸燈。
* **Tailwind CSS (CDN)**：響應式控制面板與深色合成器介面排版。
* **Web Audio API**：原生振盪器（Oscillator）、ADSR 包絡線、雙二階濾波器（BiquadFilter）、動態壓縮器（DynamicsCompressor）與即時頻譜分析（AnalyserNode）。
* **HTML5 Canvas**：60FPS 即時示波器、頻譜柱與音符粒子物理動畫。
